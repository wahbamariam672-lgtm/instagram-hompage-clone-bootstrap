# 📸 Instagram Home Page Clone

A responsive frontend clone of the Instagram homepage built using **HTML**, **CSS**, and **Bootstrap 5**. This project aims to replicate the core UI layout and styling of Instagram's web version, focusing on layout structuring, Flexbox utilization, and component styling.

---

## ✨ Features

- **Top Navigation Bar:** Fixed navbar featuring the Instagram logo, a search bar, and direct navigation/action icons (Home, Explore, Activity, Profile).
- **Stories Section:** Horizontal scrolling story avatars with custom Instagram-style gradient/red borders.
- **Post Feed:** 
  - Post header with creator avatar and username.
  - Interactive post action buttons (Like, Comment, Share, Save/Bookmark).
  - Square aspect ratio image container (`ratio-1x1`).
  - Like count, description, and preview of user comments.
  - Timestamp indicator (e.g., *1 hour ago*).
  - Built-in comment input form with a custom styled post button.
- **Sidebar (Desktop View):** Current user profile card with a "Switch" option, alongside a "Suggestions for you" section with interactive Follow buttons.
- **Fully Responsive:** Uses Bootstrap grid system and utility classes for a clean layout across different screen sizes.

---

## 🛠️ Built With

- **HTML5** - Structuring the web pages.
- **CSS3** - Custom styling and precise layout adjustments (`index.css`).
- **Bootstrap 5** - Fast layout development and responsive grid components.
- **Bootstrap Icons** - Clean vector icons for navigation and actions.
